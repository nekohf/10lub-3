# Домашнее задание к работе 10

## Условие задачи

Составить программу, которая для заданной пользователем фигуры (прямоугольная трапеция из индивидуального задания работы 9) предлагает меню выбора одной из операций:

1. рассчитать площадь;
2. вывести определение фигуры;
3. нарисовать фигуру.

Для операций реализовать собственные функции: вычисление площади, рисование фигуры заданным символом, вывод параметров фигуры и сравнение двух фигур по площади.

## Решение
1. Подключаем библиотеки.
2. Пишем функции:
    float area_trap(float a, float b, float c) — площадь трапеции, a и b — основания, c — высота;
    void draw_trap(int a, int b, int c, char d) — рисует трапецию символом d, a — высота, b — нижнее основание, c — верхнее основание;
    int get_top(int a, int b, double c) — возвращает верхнее основание, a — высота, b — нижнее основание, c — угол;
   int compare_trap(float a, float b) — возвращает разницу площадей двух трапеций.
3. Объявляем переменные в main. c — символ рисования, a — высота, b — нижнее основание, d — верхнее основание, g — угол, k — пункт меню, n — для повтора.
4. Начало цикла и ввод данных. Пользователь вводит символ, высоту, нижнее основание и угол.
5. Математические расчеты. d = get_top(a, b, g);
6. Проверка. Если верхнее основание или высота неположительные — выводится ошибка.
7. Меню. Пользователь выбирает операцию:
   - 1 — площадь через area_trap;
   - 2 — определение фигуры;
   - 3 — рисунок через draw_trap.
8. Повтор или выход. printf("Продолжить? (0 - нет, другое число - да): "); Если введен 0 — программа завершается, иначе цикл повторяется.
9. Конец.
